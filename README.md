# Quest Sync Plugin for Fallout New Vegas

**Quest Sync** is an xNVSE plugin that allows multiple players to synchronize their quest progress in Fallout: New Vegas. When one player completes a quest or objective, it automatically updates for all connected players.

## Prerequisites

- [Fallout: New Vegas](https://store.steampowered.com/app/22380/Fallout_New_Vegas/)
- [xNVSE (New Vegas Script Extender)](https://github.com/xNVSE/NVSE/releases) - version 6.0 or higher
- [FNV 4GB Patcher](https://www.nexusmods.com/newvegas/mods/62552/) (recommended)

## Installation

1. Install xNVSE by following its installation instructions
2. Copy all Quest Sync Plugin files to your Fallout New Vegas directory
   - For Steam: *Steam\\steamapps\\common\\Fallout New Vegas\\*
   - Look for FalloutNV.exe to confirm you have the correct folder
3. The plugin will be loaded automatically when you launch the game with xNVSE

## Server Setup

1. Install the Quest Sync Server on the host computer
2. Configure the server using the `Quest Sync Server.cfg` file
3. Run the server executable
4. Make sure port 25575 (default) is open in your firewall and router

## Configuration

Edit the `quest_sync.ini` file to configure the plugin:

```ini
[Network]
# The IP address of the Quest Sync server
ServerAddress=127.0.0.1
# The port of the Quest Sync server
ServerPort=25575
```

- Change `ServerAddress` to the IP address of the computer running the Quest Sync Server
- For LAN play, use the local network IP (e.g., 192.168.1.x)
- For internet play, use the public IP or hostname of the server

## Usage

1. Start the Quest Sync Server on the host computer
2. Launch Fallout: New Vegas with xNVSE on each client computer
3. Start a save (new game or saved game)
4. The plugin will automatically connect to the server
5. A notification will appear when successfully connected
6. Quest progress will now automatically synchronize between all connected players

## Features

- Synchronizes quest stages and objectives
- Works with both vanilla quests and mod-added quests
- Minimal performance impact
- Automatic reconnection if connection is lost
- In-game notifications for connection status

## Troubleshooting

- **Plugin not loading**: Verify xNVSE is installed correctly
- **Cannot connect to server**: Check server IP and port in configuration
- **Connection lost**: The plugin will try to reconnect automatically
- **Quests not syncing**: Ensure all players have the same mods installed

If you experience crashes, please try disabling all other mods to see if there's a conflict. Include a crash log generated by a [Crash Logger](https://www.nexusmods.com/newvegas/mods/82540) with any bug reports.
